# 配置自己的工具

1. 用 skill_search 和 skill_read 查已有路径、版本和成功方法；再核对实际文件、进程及目标项目要求。新会话不重复下载可用依赖。
2. 查项目官方说明和稳定版本，确认操作系统、架构、依赖和配置接口。先下载并核验官方校验值或签名，再安装到独立版本目录。
3. 备份要修改的配置和启动入口；当前工具正在运行时先准备新版，空闲后切换。不要覆盖正在使用的程序文件。
4. 用真实工具编辑配置、安装依赖或接入 MCP。遇到登录、验证码或必须由用户完成的交互，明确说明已经完成的部分和阻塞位置。
5. 核对新版本、启动路径、工具发现及用户要求的实际输出。只有文件下载完成不能称为配置成功；失败时保留旧版本并修复具体错误。
6. 通过 skill_save 保存版本、位置、校验和、配置方式、验证结果和回退方法；已有技能先读取最新 revision，合并更新。以后条件变化可随时更新。

中文技能及文本优先 skill_read/local_read_text；短 PowerShell 文本命令用 local_run_utf8，它优先使用已安装 PowerShell 7。长任务使用原生执行工具并明确 shell 路径；二进制文件用字节方式读写。不要把凭据、完整聊天或未验证猜测写成已确认经验。
