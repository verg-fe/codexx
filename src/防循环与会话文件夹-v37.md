## 新增保护

- 默认思考预算 1536 token；思考最多 60 秒，单次生成最多 150 秒。输入处理另有 180 秒上限，模型加载和查资料在生成计时之前。
- 单个任务最多 10 分钟。模型继续执行多次工具调用也受此限制；超过限制会保留进度并暂停。
- 同一轮同类异常出现 3 次后暂停。PowerShell 返回码为 0 但打印异常仍按失败处理；带探针标签的异常也会识别。
- API 错误后提示先查官方文档、检查对象类型并做最小验证。识别为 Frida 的错误会直接读取官方 Java API 文档；其他 API 要求模型使用网页工具查证。
- 搜索不会发送原始命令、私有文件路径或凭据。网页摘录作为资料保存，不能替用户授权操作。
- 拦截未知工具、缺失必填参数、损坏 JSON 与正文中的伪工具标记。取消不完整输出，禁止引擎自动重复请求。
- 超时会关闭真实上游连接，界面发出原生任务中断。若同一模型的同一生成任务仍未释放，会停止该工作台拥有的模型进程，下次启动重新加载。
- “模型与性能”提供严格、标准、宽松三档限制。原 XML 强制自检流程首次升级改为原生模式，仍可在设置里选择其他预设。

这些控制限制无进展循环，不能保证模型从此永远选对 API 或不会犯代码错误。暂停后应先看真实错误和查证结果，再给出下一步要求。

## 每个新会话一个文件夹

默认位置：`C:\my_projects\CodexSessions`。每次打开工作台或点击“新对话”，立即创建带日期、时间和随机后缀的独立空文件夹，并作为该会话默认项目目录。

“会话文件夹位置”按钮修改后续新会话的根目录。恢复已有会话使用原来目录。点击“打开项目文件夹”可指定现有项目，同时仍为该新会话保留独立目录放置新增辅助脚本、下载和交付物。编辑已有项目的实际改动仍保存在指定项目。

会话目录记录保存在 `D:\LocalCodex\session-workspaces`；目录内容不会在删除会话记录时自动删除。历史日志和旧版本备份继续保留。
