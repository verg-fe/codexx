# v40：精准搜索与异常恢复

- 保留库名、版本、API 和完整报错；已识别的技术主题优先搜索官方域名。
- 相关性排序、同名歧义过滤、无关结果自动换查询；保留独立搜索源的有效结果。
- 自动读取最多两页正文，返回匹配词与来源；正文主题匹配不代表结论已证实。
- 未找到相关证据明确返回状态，要求模型换查询或继续读取，不能凭摘要猜结论。
- 重复异常改为注入恢复提示并继续；旧版因此保存的阻塞自动解除。
- Python 异常优先取最终错误类型和说明，不把所有 Traceback 归为相同问题。
- ModuleNotFoundError 提示检查实际解释器与依赖环境。保留生成时限与无输出保护。
