# 千问 3.8 27B：本机深思考配置

2026-10-07 查询 [千问官方模型卡](https://huggingface.co/Qwen/Qwen3.8-27B#best-practices) 与 [当前 Jack V2 模型作者说明](https://huggingface.co/JackAgentLead/Jack-3.8-27B-V2-VL-16GB-VRAM)。

## 官方资料

千问默认启用深入思考和历史思考保留，并提醒代理场景中思考过少可能造成更多失败和重试。官方使用 `xhigh` 深度，思考模式采样值为 temperature 1.0、top_p 0.95、top_k 20、min_p 0、presence_penalty 0、repetition_penalty 1.0。

模型卡对 1M 上下文的大型部署给出很宽的思考和回答容量；该部署条件与本机 16GB 显卡、97,280 token 对话窗口不同。官方的一项代码任务评测使用 32,768 token 总输出预算，因此本机默认采用这一总量作为工程起点，并给思考单独保留 16,384 token。这个划分是本机折中选择，不是官方发布的唯一最优思考值。

Jack 作者建议关闭 MTP、加载视觉投影器，并将 Q4 KV 作为早期推荐。本机已有这些设置，继续使用。保留工作台当前的原生指令预设，其他预设可自行选择。

## 已设置的默认值

| 设置 | 值 |
|---|---|
| 思考深度 | xhigh / 深入思考 |
| 思考预算 | 16,384 token |
| 总输出预算（包括思考、正文和工具参数） | 32,768 token |
| 思考最长时间 | 15 分钟 |
| 单次生成最长时间 | 20 分钟 |
| 单次任务最长时间 | 60 分钟 |
| 已开始生成后无新内容 | 90 秒后取消 |
| 同类异常重复 | 3 次后暂停 |
| 输入处理最长时间 | 5 分钟 |
| 历史思考保留 | 开启 |

“防止思考和报错循环”提供 8K 日常、16K 推荐、32K 复杂三档。切换档位会同步更改思考预算、总输出和时间限制，并重新加载模型。时间限制是最长允许时间，不要求每轮把预算用完。

输入自动整理阈值为长输出预留空间：当前 97,280 token 窗口在默认档位下约 62,464 token 输入时自动整理，完整历史仍保留在本地。

## 本机速度依据与边界

读取已有 `D:\LocalCodex\logs\model.log`：最近 100 条生成记录中，95 条至少输出 100 token，中位速度约 30.67 token/秒。这些是历史日志数据，没有重新跑性能测试。

按该速度估算，16,384 token 约需 8.9 分钟，32,768 token 约需 17.8 分钟，不含输入处理、查资料、工具执行和模型加载。15/20 分钟的单次限制给当前速度留出余量；显存竞争和更长上下文可能导致速度下降。

该配置扩大正常推理空间，同时保留真实错误干预、工具调用检查、卡住取消和有限预算。尚未用完整任务对比证明 16K 优于其他档位。
